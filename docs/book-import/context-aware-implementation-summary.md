## 🚀 技术特点

### 1. 渐进式上下文累积
```
全局分析 → 第1批 → 更新上下文 → 第2批 → 更新上下文 → 第3批 → ...
(建立基础)  (处理)    (累积新信息)  (处理)    (继续累积)  (处理)
```

### 2. 智能内存管理
- **角色信息**：完整保留主要角色的详细档案
- **剧情线**：跟踪所有活跃剧情线的当前状态
- **批次历史**：只保留最近3批，避免内存膨胀
- **世界观数据**：累积发现的地点、组织、规则

### 3. 动态Token预算
- **前期批次**（1-3）：更多上下文预算，建立完整认知
- **后期批次**（4+）：适度压缩预算，保持高效处理
- **自适应调整**：根据批次位置和上下文大小动态调整

### 4. 容错机制
```
新功能成功 → 使用上下文感知大纲 ✅
     ↓ 失败
原有逻辑 → 降级到批处理模式 🔄
```

## 🔧 使用方式

### 自动启用
新功能已集成到现有系统中，**无需任何配置**即可自动启用：

```typescript
// 在 preview-generator.ts 中
const generator = new ContextAwareOutlineGenerator(userId)
return await generator.generateOutlinesWithContext(chapters, suggestion)
```

### 降级机制
如果新功能失败，系统会自动降级到原有的批处理模式：
```typescript
try {
  // 尝试使用上下文感知生成
  return await generator.generateOutlinesWithContext(...)
} catch (e) {
  // 降级到原有方法
  return await generateReverseOutlinesFallback(...)
}
```
